# Computer Graphics Projects

This folder contains my Computer Graphics projects developed using C++ and graphics.h.

## Projects

### 1. Virtual Eye Simulation

A simple 2D Computer Graphics project that creates a virtual eye. The pupil can be moved using the keyboard arrow keys.

### 2. 2D Transformations

A Computer Graphics program demonstrating basic 2D transformations such as Translation, Scaling, Rotation, and Reflection.

**Transformations Covered:**
- Translation
- Scaling
- Rotation
- Reflection

 ### Technologies Used:**
- C++
- Turbo C++
- graphics.h
