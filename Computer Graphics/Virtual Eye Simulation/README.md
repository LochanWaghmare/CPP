# Virtual Eye Simulation

A simple Computer Graphics project made using C++ and `graphics.h`.

## About

This project creates a basic virtual eye using 2D graphics primitives such as ellipse, circle and arc.

The pupil can be moved in different directions using the keyboard arrow keys.

## Controls

- Left Arrow → Move left
- Right Arrow → Move right
- Up Arrow → Move up
- Down Arrow → Move down
- ESC → Exit

## Technologies Used

- C++
- Turbo C++
- graphics.h
